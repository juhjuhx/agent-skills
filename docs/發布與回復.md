# 發布、遷移與回復

## 發布邊界

本輪在隔離 clone 準備縮小範圍的 V3，fresh checks／獨立 review 通過後 commit、push `release/personal-tool-master-v3`、PR against main。**停在 Phase A；不自動 merge、tag 或 GitHub Release。** 既有 26 個其他 PR 不在此次 merge 範圍。

## 遷移

本次公開快照包含母技能、14 個核實來源核心技能、V3 helper／advisory adapters／tests／docs／installer。其他未完成權利確認的材料不打包；你的本機完整技能庫與入口不做刪除／更新。不得從本次 main-based installer 自動覆蓋 dirty 安裝，另用乾淨 clone。乾淨舊版 checkout 明示 ff-only 更新會移除本次排除的 tracked 檔案；先閱讀範圍差異並備份需要保留的合法材料。

router advisory，宿主權限保持。不存在 RuntimeDecision／TTL／TaskLease／ActionGrant／SQLite authority 前置 gate；舊 enforcing 沒有打包或預設安裝。可選 OpenCode 入口不改全域設定。

## 回復

安裝器切換 managed profile/config、兩個 optional adapter、新建宿主 links 失敗會回復舊內容；成功重選的 backup 路徑會列出。clone／fetch 本身不屬 filesystem transaction，並行安裝不支援。

Phase A 未合併 PR 不影響 main。需要更正發布分支使用正常新增 commit；不 force-push、reset 使用者工作或重寫歷史。未來正式合併後的回復應另建 reviewed revert PR，重跑安裝與 non-blocking tests。
