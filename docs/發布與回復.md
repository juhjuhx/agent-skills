## 遷移與個人資料

公開快照只有 14 個核心技能、V3 helper／advisory adapters／tests／installer／docs。個人完整庫、dirty 工作、外部 links、legacy DB 與封存保持原位；未核實材料不是公開依賴。乾淨舊 checkout 明示 ff-only 更新會移除新版排除的 tracked 材料，需先保存要保留且可合法使用的內容。

router／catalog 故障不能禁用宿主工具，也不需要 RuntimeDecision、TTL、TaskLease、ActionGrant 或 SQLite gate。optional OpenCode 入口不改全域設定；既有 plugin 不覆寫，舊 enforcing 不移回 active。

## 回復

installer 為 managed 集合、config、optional adapter 與本輪新建 links 提供檔案切換失敗回復。成功重選會列出舊 managed links 備份；舊 config 不另永久保存，需要完整人工回復時先備份 config 與入口身分。clone／pull 不屬 transaction，並行／斷電恢復未驗證。

停用 optional adapter 前核對身分，再移至 plugins-disabled，native Skill 可繼續使用。已合併版本如需回復，另建 reviewed revert PR 並重跑相關驗證；不 force-push、reset 或 clean 個人工作。詳細圖與操作條件見 [備份與回復](architecture/V3_RELEASE_AND_MIGRATION.md)。
