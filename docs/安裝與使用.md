# 安裝與使用

需求：Git、Python 3.10+；wrapper 需 Bash。Node 只在 optional OpenCode adapter 或相關測試需要。V3 使用普通技能檔案與 JSON，不需要 SQLite、daemon 或 policy server。

V3 程式 [PR #27](https://github.com/juhjuhx/agent-skills/pull/27) 已合併 main。正式文件、tag／Release 的最新身分見 [發布與遷移](architecture/V3_RELEASE_AND_MIGRATION.md)；安裝到最新 main 不等於已取得某個正式 tag。

## 乾淨來源與安裝

先在獨立乾淨路徑 clone 公開來源，不覆寫個人 dirty 庫：

```sh
git clone https://github.com/juhjuhx/agent-skills.git agent-skills-v3
cd agent-skills-v3
python3 runtime/skills-router/tool_master.py route \
  '研究此專案並比較官方資料' --root . --host generic
```

載入 `using-superpowers/SKILL.md` 即可使用母技能。需要宿主入口時：

```sh
bash install.sh --minimal
# 或 --default、--all、--category essential,coding
```

`--minimal` 是 3 個核心技能；`--default`／`--all` 是此公開快照的全部 14 個，正文仍按需載入。分類只有 essential／coding；個人完整技能庫與其他第三方內容不在本次包內。

首次 clone 到 `<HOME>/.agents/skills`，啟用集合在 `<HOME>/.agents/skills-enabled`，installer config 在 `<HOME>/.agents/skills-config.json`。只有已存在的受支援宿主目錄且 skills 入口缺少時才建 link；既有非 managed 入口保持。`--no-links` 不建宿主與 universal pointer，但仍準備 managed 集合與 config；`--home <disposable_directory>` 供隔離測試。

## 既有 checkout 與更新

既有乾淨 checkout 不自動 pull；dirty／untracked、wrong origin、nonmanaged enabled 內容會拒絕。明示 `--update` 才接受 tracking origin 且無 ignored／cache 的 checkout，以 ff-only 更新，不 stash、reset 或 clean。

乾淨舊版明示更新到精簡版時，Git 會移除新版排除的 tracked 技能；保護 dirty 不代表全部舊 tracked 內容仍存在。先備份需要保留且可合法使用的材料與 config。成功重選留下舊 managed links 備份；檔案切換失敗回復舊 config／links，clone／pull 不在 transaction 中，並行／斷電不在已驗證範圍。

安裝驗證只在 disposable HOME 執行，不對真實個人庫跑 smoke installer。

## OpenCode opt-in

```sh
bash install.sh --minimal --opencode-advisory
opencode run --agent '工具大師V3' 'using-superpowers：理解這個專案並完成下一項工作'
```

只複製 [advisory plugin](../runtime/skills-router/adapters/opencode/skills-router.js) 與 [可選 primary](../runtime/skills-router/adapters/opencode/工具大師V3.md)，不改 `opencode.json`、model、default agent 或 permissions。目的檔已存在就拒絕；先備份／停用既有插件，核對新 plugin id 為 `personal-tool-master-v3`。舊 enforcing 不移回 active plugins。

adapter 預設只傳 task 給 helper，Agent 仍需核對本次真實工具 schema。未知 catalog 格式保持，工具執行 hook 為 no-op；逾時或路由失敗使用手動流程。停用前核對檔案身分，移到 plugins-disabled 後 native Skill 仍可用。

## 其他宿主與長任務

Codex 使用 native Skill／READ／exec／PATCH；Claude 可載入母技能，repo 提供 hook 契約但不預設安裝或登記；Hermes／DSH 以當次工具 schema 為準，沒有專用 installer 入口。映射知識不是完整 live E2E 支援保證。

重要長任務由 Agent 保存 TASK／PLAN／STATE，新 session 先讀狀態並核對現物。helper 不保存 task、不執行工具、不需要私人 DB。metadata 失效或 helper 缺少時手動選技能，宿主原生權限仍有效。

macOS 的候選本機 smoke 與 GitHub Ubuntu CI 分開。Windows symlink、所有宿主版本與小模型未全面驗證；上游按需 scripts／references 不會因 installer 自動啟動服務或視覺 companion。見 [工作流程與工具映射](architecture/V3_WORKFLOW_AND_TOOL_MAPPING.md)、[測試與限制](architecture/V3_TESTING_AND_LIMITATIONS.md) 與 [儲存與狀態](architecture/V3_STORAGE_AND_STATE.md)。
