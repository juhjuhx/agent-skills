# 安裝與使用

需求：Git、Python 3.10+；wrapper 需 Bash。Node 只在使用 OpenCode adapter 或相應 tests 時需要。V3 不需要 SQLite、daemon、policy server。

## Release branch 候選

Phase A 只 push branch／開 PR，main 未合併前不能使用 main 的安裝器當 V3。先在另一個乾淨路徑 clone release branch，載入母技能或執行 helper。不要在既有 dirty skills 庫上覆蓋。

```sh
git clone --branch release/personal-tool-master-v3 https://github.com/juhjuhx/agent-skills.git agent-skills-v3
cd agent-skills-v3
python3 runtime/skills-router/tool_master.py route '研究此專案並比較官方資料' --root . --host generic
```

## 正式合併後的乾淨安裝

```sh
git clone https://github.com/juhjuhx/agent-skills.git
cd agent-skills
bash install.sh --minimal
# 或 --default、--all、--category essential,coding
```

`--minimal` 3 個核心技能；`--default`／`--all` 14 個已核實來源的技能，正文仍按需讀。其他分類／第三方技能未納入本次精簡快照，不能假稱仍打包。

首次 clone 至 `~/.agents/skills`，選定入口置於 `~/.agents/skills-enabled`。只在已有宿主目錄的 skills 入口不存在時建立 link；使用者既有非 managed 目錄會保留並提示。`--no-links` 只準備選定集合；`--home <disposable_directory>` 供測試。

已有乾淨 checkout 不自動 pull。dirty／untracked 立即拒絕；明示 `--update` 才允許 origin 相符、tracking origin 且沒有 ignored/cache 的 checkout ff-only 更新。不 stash／reset／clean。未追蹤或修改過的使用者技能會因 dirty 檢查受到保護；乾淨舊版 checkout 明示更新到精簡版時，Git 會移除本次不再打包的 tracked 技能。更新前先閱讀範圍差異並保留需要的合法內容於獨立備份。成功切換 profile 時输出 previous managed links 備份；失敗回復舊 config／links，並行安裝不在支援範圍。

## OpenCode opt-in

```sh
bash install.sh --minimal --opencode-advisory
opencode run --agent '工具大師V3' 'using-superpowers：理解這個專案並完成下一項工作'
```

只複製 advisory plugin 與可選 primary，不改 `opencode.json`、model、default agent、permissions。目的檔存在就拒絕，不覆寫既有 enforcing 或 advisory。先由使用者備份／停用舊插件。核對 plugin id 為 `personal-tool-master-v3`；舊 enforcing 不得移回 active plugins。

停用 V3 時，核對檔案身分後把該 optional plugin 移至 plugins-disabled；native Skill 仍可用，無 hash monitor。

## 其他宿主與工具

Codex 可用 native skill／READ／exec／PATCH；Claude native Skill 可讀母技能但不預設安裝 hook；Hermes／DSH 以當次工具 schema 為準。mapping 知識不是 live E2E 支援保證。

metadata 失效或 helper 不可用時手動選技能與工作流程；read/search/bash/skill 仍由宿主原權限控制。長任務保存 TASK／PLAN／STATE，新 session 核對現物後續接。

macOS 已做本機 smoke。Linux 以實際 PR CI 為準；Windows symlink 及其他宿主版本未全面驗證。Superpowers 上游輔助 scripts／references 是按需素材，不會隨安裝自動啟動服務、工具或視覺 companion。

## English

Use the release branch for candidate evaluation; normal main-based installation applies only after independent merge verification. Run `bash install.sh --minimal` for 3 core skills or `--all` for all 14 bundled skills. The optional OpenCode adapter requires explicit opt-in. Existing dirty checkouts, user-owned directories, global settings and plugins are preserved.
