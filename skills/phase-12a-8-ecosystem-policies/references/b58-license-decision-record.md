## License Terminology

| Term | Meaning |
|------|---------|
| FREE OF CHARGE | No monetary cost required |
| OPEN SOURCE | OSI-approved, source available, commercial use permitted |
| FREE SOFTWARE | Freedom to use, study, modify, redistribute |
| COMMERCIAL USE | Use in business/monetary context — permitted under GPL-3.0 |
| COPYLEFT | Derivative works must carry same license terms |
