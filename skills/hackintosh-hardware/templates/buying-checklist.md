# 黑蘋果筆電購買檢查清單

## 基本規格要求
- [ ] Intel 第 8 代以上 CPU（8 代以上才原生支援 macOS Big Sur+）
- [ ] Intel 核顯（UHD 620/630 或 Iris Plus）
- [ ] 避免 AMD 獨立顯卡（除非是 MacBook Pro 16" 2019 的原廠 RX 5500M）
- [ ] WiFi 卡：Intel AC 系列（如 8265、8275、9260）或Broadcom
- [ ] 避免 Realtek 網卡/WiFi（需要額外驅動）

## BIOS/UEFI 設定檢查
- [ ] 可以關閉 Secure Boot
- [ ] 可以關閉 VT-d（或知道如何禁用）
- [ ] 可以關閉 Fast Boot
- [ ] SATA 模式可以切換到 AHCI（非 RAID）
- [ ] 可以調整 ACPI 設定

## 常見相容型號

### ThinkPad 系列
- T480/T490/T490s
- X280/X390
- P52/P53

### Dell Latitude 系列
- 7400/7490
- 5490/5590
- 9410

### HP EliteBook 系列
- 840 G5/G6/G7
- 830 G6/G7
- 650 G5/G6

## 價格參考（二手，2024）
- ThinkPad T490: NT$12,000-18,000
- Dell Latitude 7400: NT$10,000-15,000
- HP EliteBook 840 G7: NT$12,000-16,000

## 不建議的型號
- 帶有 NVIDIA 獨顯的筆電（需要禁用 NVIDIA）
- 帶有 AMD 獨顯的非 Apple 筆電（驅動困難）
- Realtek 網卡/WiFi 的筆電
- 2018 年前的筆電（效能不足）
