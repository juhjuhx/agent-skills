## 使用說明

### 安裝位置

- **Hermes:** `~/.hermes/skills/`
- **Agents:** `~/.agents/skills/`
- **OpenCode:** `~/.config/opencode/skills/`

### 載入方式

```bash
# Hermes
hermes skills list

# OpenCode
opencode skills list

# 手動載入
skill_view(name='skill-name')
```

### 遷移腳本

使用 `skill-manager.sh` 同步 skills 到不同 agent:

```bash
cd ~/.agents/skills
./skill-manager.sh sync
```
